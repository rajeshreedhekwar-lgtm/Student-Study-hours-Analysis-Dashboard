# Student-Study-hours-Analysis-Dashboard
An interactive Student Study Hour Analysis Dashboard built with Python to visualize study habits, attendance, grades, and academic performance based on their study hours.

## Project Overview

The **Student Study Hour Analysis Dashboard** is a Python-based data analysis and visualization project.

The purpose of this project is to analyze students' study hours and understand their relationship with academic performance.

The dashboard uses student information such as study hours, attendance, assignment scores, internal marks, final marks, grades, and results.

## Dataset

The dataset contains information about 19 students.

### Main Features

- Student
- Gender
- Department
- Semester
- Study Hours per Day
- Attendance %
- Assignment Score
- Internal Marks
- Final Marks
- Grades
- Result

## Dashboard Features

The dashboard provides:

- Total number of students
- Average study hours
- Average attendance
- Average final marks
- Pass percentage
- Study Hours vs Final Marks
- Average Study Hours by Department
- Average Final Marks by Study Hours
- Grade Distribution
- Pass/Fail Distribution

## Technologies Used

- Python
- Pandas
- Matplotlib
- NumPy
- Excel

## How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Install the required libraries

```bash
pip install -r requirements.txt
```

### 3. Keep the files in the same folder

Make sure `dashboard.py` and `studyhours(1).xlsx` are in the same folder.

### 4. Run the dashboard

```bash
python dashboard.py
```

The dashboard will open and display all the charts on one page.

## Project Objective

The objective is to transform raw student data into an easy-to-understand visual dashboard and identify patterns between study habits and academic performance.

## Conclusion

This project demonstrates how Python and Excel data can be combined for data analysis and visualization. The dashboard makes it easier to understand student study patterns and academic performance.
